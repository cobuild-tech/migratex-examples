<h1 align="center" style="font-weight: bold;">ToDo ✔️</h1>

![react](https://img.shields.io/badge/React-red?style=flat&logo=react)

<p align="center">
<b>This application is a ToDo App, where users can create their activities
separating them by priority (light, normal, medium, high), and then delete or complete the activities.</b>
</p>

This is a React (Vite + TypeScript) port of the original Angular ToDo App, with equivalent
behavior, styling, and test coverage.

## Technologies

- React 19
- TypeScript
- Vite
- SCSS
- Vitest + React Testing Library

## Getting Started

### Prerequisites

- Node 18+

### Install project

```
git clone <this-repository-url>
npm install
```

### Start dev server

```
npm run dev
```

### Run tests

```
npm run test
```

### Build for production

```
npm run build
```
